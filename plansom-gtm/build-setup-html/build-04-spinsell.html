PLANSOM · GTM PILLAR 04 · BUILD & SETUP

Pillar 04 — Spin Sell System

Runs on the same HubSpot deals; adds discovery, playbooks, and forecasting.

Operational build for the human selling motion — how HubSpot deals, playbooks, call tooling and forecasting are set up so every meeting is qualified and moved consistently.

Tooling

  • HubSpot Sales Hub: Deals (from ‘Meeting booked’ onward), Playbooks, Meetings scheduler, Quotes, Sequences (post-meeting).
  • Call recording/notes: Fireflies/Otter (already in the stack) → log to the deal.
  • Docs: story deck, ROI calculator, battlecards (Content OS) linked on the deal record.

Qualification data model (required at each gate)

FieldPurpose
TriggerThe ‘why now’ (mirrors outreach signal)
Pain owner / authorityWho feels it / can buy
Metrics (implication)Quantified cost of the problem
TimelineWhen they’d start / decide
ChampionInternal advocate

HubSpot Playbooks (SPIN)

Create a ‘Discovery — SPIN’ playbook with the Situation/Problem/Implication/Need-payoff question bank (Pillar 04 doc). Reps run it on the call; answers save to deal properties.

Workflows

WorkflowTrigger → actions
Discovery prepMeeting booked → create prep task + attach deck/battlecard
Stage tasksOn each deal stage → create the next task (recap, trial nudge, ROI, proposal)
Stalled dealNo activity 7 days → alert owner + suggested next step
Proposal/quoteEnter ‘Evaluation’ → generate quote from template (seats × price)

Forecasting & dashboards

  • Weighted pipeline by stage probability; meeting→trial and trial→win vs targets; win/loss reasons (feed Market scan).
  • Objection tracker — tag objections on deals → feed FAQ + battlecards.

Setup checklist

  1. Add qualification properties + stage gates.
  2. Build the SPIN playbook + snippets/templates.
  3. Build post-meeting sequence + stage-task workflows.
  4. Set up quotes + product/price library.
  5. Build the forecast + win/loss dashboard.
  6. QA on 3 live deals.
