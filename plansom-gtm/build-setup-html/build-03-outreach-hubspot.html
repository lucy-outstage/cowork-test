Pillar 03 — Outreach System

CRM: HubSpot (Sales Hub + Marketing Hub). The single source of truth for the sales-led motion.

Everything below is a from-scratch HubSpot build for the outreach engine — the data model, the funnel, the automation and the reporting needed to run ~227 meetings/mo into trials, cleanly attributed and compliant.

1 · Architecture & objects

  • HubSpot as source of truth for Contacts, Companies, Deals, Activities. Sales Hub (sequences, deals, tasks) + Marketing Hub (lists, scoring, forms).
  • Sending stays outside HubSpot for cold outbound (dedicated domains/inboxes via Smartlead/Instantly) — replies + engagement sync back to HubSpot. HubSpot sends warm/1:1 and marketing email only (protects the primary domain).
  • Connected tools: LinkedIn (Sales Nav + agency tool), Apollo (enrichment), calendar via HubSpot Meetings, product trial events via API/webhook, Slack for alerts.

Gate each stage with a required field (e.g. can’t reach ‘Discovery held’ without a completed qualification property). Probabilities feed the forecast.

7 · Sequences (Sales Hub / sending tool)

  • Email 4-step + LinkedIn 4-step (copy in the Outreach pillar doc) built as sequences; LinkedIn steps as manual tasks.
  • Enrollment: on entering an ICP/signal list. Auto-unenroll: on reply, meeting booked, unsubscribe.
  • Per-segment variants (A/B/C) with the segment’s trigger language.

9 · Tasks, queues & SLAs

  • Task queues per rep: ‘LinkedIn steps’, ‘Call/positive replies’, ‘Meeting prep’.
  • SLA: positive reply worked < 2 business hours; MQL actioned same day; meeting recap logged < 1 hour.

11 · Reporting dashboards

  • Outbound funnel — contacts by lifecycle + deals by stage; conversion each step.
  • Channel performance — meetings + cost per meeting (LinkedIn ~$43 / email ~$49) vs target.
  • Sequence performance — reply %, positive %, meeting % per sequence/segment.
  • Meeting → trial → win — with the 50% / 20% targets.
  • Rep activity & SLAs — tasks, response times.

12 · Data hygiene & compliance considerations

  • Deliverability: dedicated cold domains + warmup; keep the primary domain for warm/marketing only.
  • GDPR/CCPA: lawful basis for outreach, one-click unsubscribe, honour DSARs via suppression; log consent.
  • Property governance: one owner for the property library; no free-text where a dropdown belongs.
  • Required fields as stage gates prevent ‘ghost’ pipeline.

13 · Setup checklist (in order)

  1. Connect domains/inboxes + calendar; verify sending/deliverability.
  2. Create the property library (contact/company/deal) above.
  3. Build the ‘Outbound Sales’ pipeline + stages + probabilities + gates.
  4. Import + enrich ICP lists A/B/C; build active lists + suppression.
  5. Configure lead scoring + MQL threshold.
  6. Build sequences (email + LinkedIn tasks), per-segment variants.
  7. Build the 10 workflows; connect Slack + product webhook.
  8. Build the dashboards.
  9. QA with 10 test contacts end-to-end; check attribution + compliance.
  10. Go live; review KPIs weekly (Scheduled Collaboration).

14 · Ownership

RevOps owns the HubSpot build + hygiene; SDR/agency owns sequences + tasks; AE owns deals from ‘Meeting booked’. Weekly review in the Marketing/Outreach check-in.
