Pillar 09 — Traffic System

Tracking-first: GA4 + product analytics + HubSpot + ad platforms + consent.

Operational build for paid + organic traffic — the tracking plan comes first, then the automation that turns visits into attributed trials.

Tooling

  • GA4 + Google Tag Manager; product analytics; a consent/cookie tool.
  • HubSpot forms + tracking code on all pages/landing pages.
  • Ad platforms: LinkedIn, Meta, Google (+ offline-conversion import from HubSpot).

Tracking plan (build this before scaling spend)

ElementSpec
UTM governanceEnforced source/medium/campaign/content on every paid + social link
Conversion eventsvisit → signup → activation → paid (client + server-side)
AttributionFirst + last touch in HubSpot; self-reported ‘how did you hear’ at signup
ConsentBanner + regional rules; suppress tracking pre-consent

Workflows

Dashboards

  • CAC per channel (LinkedIn ~$480 / Meta ~$233 / Google ~$260) vs target; funnel by source; SEO/GEO traffic + rankings + AI-referrals.

Setup checklist

  1. GTM + GA4 + consent live; verify events.
  2. HubSpot tracking + forms on all pages.
  3. UTM template + naming convention.
  4. Ad pixels + offline-conversion import.
  5. Audience-sync + inbound workflows.
  6. Channel CAC dashboard; then scale spend.
