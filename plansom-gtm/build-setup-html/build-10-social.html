Pillar 10 — Social Media System

Scheduling + UTM tracking + DM-to-CRM + listening.

Operational build to run founder-led + brand social as a measurable pipeline source, not a vanity channel.

Tooling

  • Scheduling: Buffer / Hootsuite / HubSpot Social (company + founder accounts).
  • Tracking: UTMs on every outbound link; HubSpot ‘Social’ source.
  • Listening: the Social Listening OS (Content OS) feeds signals to Outreach.

Workflows & process

WorkflowTrigger → actions
Calendar & approvalWeekly content plan (5 pillars) → draft → approve → schedule
DM → CRMInbound DM / profile lead → create HubSpot contact + task (warm pipeline)
Link trackingAll links UTM-tagged → attribute social → trial
AmplifyNew customer win / plan shared → repurpose to social (viral loop)

Dashboards & checklist

  • Reach → profile visits → trials by channel/account; founder vs brand performance; pipeline from social.

  2. Set UTM convention + HubSpot source.
  3. Build the DM→CRM + amplify workflows.
  4. Stand up the content calendar (5 pillars).
  5. Build the social→pipeline dashboard.
