## Sales process dashboard

Open `index.html` in a browser to view the visual dashboard.

It contains three sections:

1. **Pipeline overview** — a swimlane recreation of the Lucid chart (9 stages × 6 lanes) with existing AI agents (blue) and recommended Glean agents (purple) placed in-context.
2. **Existing AI agent roster** — Enzo, Jarvis, Reginald, Jeeves, Lurch, and two unnamed agents, with the stage and lane each one sits in.
3. **Where Glean agents would be most helpful** — eight ranked opportunities (High / Medium / Coverage gap) with the rationale for each placement.

The two stages with no AI coverage today — *Account Routing & Sales Assignment* and *Onboarding* — are called out as coverage gaps.
